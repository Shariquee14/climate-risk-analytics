About this project

Objective

Forecast daily average temperature and rain chance for the next 7 days from recent weather observations, and analyse long-term climate trends, using machine learning.

Method

  1. Data: {{ n_days }} daily records ({{ start }} to {{ end }}): max/min temperature, humidity, rainfall, wind speed, pressure.
  2. Features: today's readings, temperature lags (1, 2, 3, 7 days), rolling averages, rolling rainfall, pressure change, and day-of-year (sine/cosine) for seasonality.
  3. Models: Linear Regression, Random Forest and Gradient Boosting are compared against two baselines (persistence and climatology); the best by RMSE ({{ art.best_model }}) forecasts temperature. A Random Forest classifier predicts rain probability. One model per horizon (+1 … +7 days).
  4. Evaluation: strict time-based split — trained on the earlier part, tested on the most recent {{ art.n_test }} days. No shuffling, no future leakage.
  5. Climate analysis: annual means, linear warming trend (with p-value), seasonal climatograph, rainfall totals.

Important note about the data

The bundled dataset is synthetically generated to behave like a central-India climate (hot summers, June–September monsoon, mild winters, slight warming trend). It is not a real weather record. To use real data (e.g. from Open-Meteo, NASA POWER or Kaggle), save a CSV with columns date, temp_max, temp_min, humidity, rainfall, wind_speed, pressure as data/weather_data.csv and run python train.py.

Limitations

  • Statistical models on one location's history cannot match physics-based numerical weather prediction.
  • The "Your Readings" page assumes steady recent history because it receives a single day of input.
  • Likely ranges are approximate (based on typical test error, 80% level).
